# Веб-приложение для управление сетлистами для группы «Света НЕТ»
Веб-приложение для управления концертными сетлистами на Django, Django REST Framework и React, позволяющее хранить базу песен, формировать сетлисты концертов, отображать тексты песен зрителям и музыкантам и управлять всем через удобную административную панель
